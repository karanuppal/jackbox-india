# jackbox-india

An Indian Jackbox-style party game platform (working title **Tamasha**), whose
first game is **Khooni Sawaal** — a faithful Trivia Murder Party-style
horror-comedy trivia show, fully localized to India: Hinglish host voiceover,
Indian pop-culture question bank, Ramsay-horror-meets-Doordarshan art direction.

Players join from their phone browsers with a 4-letter room code; the show runs
on a shared host screen. No app install.

**Start here: [PLAN.md](PLAN.md)** — the master plan with every design decision
made up front (game rules, platform spec, art direction, content policy, VO
pipeline, architecture, milestones).
